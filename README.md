# 🎮 STEEL RAIN: Heavy Warfare

Тяжёлый 3D-шутер, написанный на **C#** с использованием графической библиотеки **Raylib**.

## 🚀 Скачать игру
Готовый билд (Windows x64) можно скачать в разделе **[Releases](https://github.com/rutubermark-beep/STEEL-RAIN-Heavy-Warfare/releases)**. 
Никаких установщиков не нужно — просто скачай `.zip`, распакуй и запусти `SteelRain.exe`.

## ✨ Особенности
- **Экран загрузки** с процедурным 3D-фоном и спиннером.
- **Главное меню** в стиле современных шутеров.
- **Меню настроек**: чувствительность мыши, громкость и FOV.
- **Процедурная музыка**: эпичный саундтрек генерируется прямо в коде!
- **Кроссплатформенность** (код можно собрать под Linux/Mac).

## 🎮 Управление
- **Мышка** — навигация по меню, настройка ползунков.
- **ESC** — вернуться в меню / закрыть настройки.
- *(В будущем здесь появится управление персонажем)*

## 🛠 Технологии
- Язык: **C# (.NET 8)**
- Графика и звук: **Raylib-cs**
- Сборка: `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`
